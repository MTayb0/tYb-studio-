Film & Animation Lab

Local-first cartoon looks, storyboard planning, character concepts, frame keying and calibrated image measurements

Honest capability note

These are working browser-native creative tools. This update adds more local stylization looks and a broader cartoon workflow. Toon filters are image-processing approximations, the character builder creates SVG concepts, measurement uses a known reference in a flat image, and chroma key is basic. True AI rotoscoping, stable 3D character replacement, camera tracking, LiDAR room scans, voice cloning, physics simulation and full animation rendering need dedicated models/engines and are not claimed here.

1. Toon & frame lab

Load a local photo or video, preview a frame, apply a stylized look and export a still. Use the separate video player to scrub or play.

Choose a photo or video to begin.

2. Basic green / color key

Remove pixels close to one selected color from the current canvas frame. Transparent PNG export is supported; this is not AI matte extraction.

Load media first. Best results use an evenly lit solid-color background.

3. Calibrated image measure

For a paused frame or photo, enter the real length of a visible reference, then tap its two endpoints. After calibration, tap any two points to estimate their distance in the same image plane.

Load a photo or pause a video frame first. Perspective makes estimates less accurate away from the reference plane.

4. Script → storyboard

Turn a premise into five editable shot beats for a short film, episode, comic or vertical short.

No storyboard yet.

5. Reusable character concept builder

Build a simple mascot concept and export it as SVG artwork. It can be reused in Design Studio; it is not a rigged character.

Choose options and create a character.

6. Narrator / character voice preview

Uses the device/browser's speech synthesis voices. Available languages and voice quality vary by device; no voice cloning is performed.

Advanced Tools

OCR & Document Perspective

OCR uses Tesseract.js language data downloaded when needed. Perspective correction uses OpenCV.js and requires manually supplied corner coordinates normalized to 0–100%.

AI Background Cutout

Loads MediaPipe Selfie Segmentation on demand. This model targets people, not arbitrary objects; results vary and internet is required to download the model. Keep the app open while it processes.

Video Transcoder

Uses FFmpeg.wasm loaded on demand for file-based trim/transcode and audio-preserving operations when the browser supports SharedArrayBuffer and required headers. Large files can exceed mobile memory.

Backup, Restore & Cloud Sync Setup

Voice & Subtitles

Voice processing studio and automatic subtitle pipeline

Voice Studio

Load audio or record from the mic, adjust speed, pitch and EQ, then export WAV. Speed and pitch are linked by resampling — true formant-preserving voice transplant is not possible inside a browser, and this tool never claims otherwise.

Subtitle Studio

Transcribe with the browser speech engine (Chrome/Edge with internet — timings are approximate and fully editable), or type cues manually. Export SRT/VTT, or burn subtitles into a new WebM video.

AI Lab

AI rotoscoping, character overlay, 3D virtual sets and on-device AI

AI Rotoscope

Automatic subject matte using MediaPipe segmentation — a true step above color keying for people. Loads a small model on first use, then runs locally.

AI Character

A cartoon, robot or animal avatar driven by your real facial movement (head position + jaw). This is a live avatar overlay, not a full human-to-character performance replacement.

3D Virtual Set

A simple WebGL studio set with preset camera moves (dolly, orbit, crane, wide). Loads three.js on first use (~600 KB). This is a lightweight virtual set — not an Unreal/Blender-class production engine.

Local AI

On-device models via transformers.js — nothing is uploaded. First use downloads the model once (background removal ~45 MB, captioning ~90 MB), then it is cached. Desktop-class browsers with ~1 GB free memory recommended; full offline text-to-image suites exceed mobile limits.

Platform honesty

These capabilities are not available inside a browser app and TYB Studio does not pretend to offer them: LiDAR room scanning (ARKit/ARCore are not exposed to web apps), production-grade real-time camera tracking, Unreal/Blender-class 3D production engines, and true voice transplant/formant control. Where a partial exists, it is labeled as such above.
